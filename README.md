# pre_commit_cruft

Pre-Commit hook for Cruft

![pre-commit workflow](https://github.com/jlec/pre-commit-cruft/actions/workflows/pre-commit.yml/badge.svg)

cruft is a convenient tool for cookie-cutter version. The hook is ensuring you are on
the latest cookie version.
